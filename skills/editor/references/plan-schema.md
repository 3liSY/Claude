# edit_plan_vN.json: the full format

One file per version in `projects/<p>/plan/`. It is the single source of truth: the sheet, the EDL, the bridge operations, the notes and the learning loop all read it. Never edit an applied version in place for big changes: `plan.py bump` it first.

## 1. Top level

```json
{
  "schema": "editor-plan/1",
  "version": 1,
  "project": "2026-10-22_gan14-review",
  "channel": "syrian-rubik",
  "created": "2026-10-22T18:04:11",
  "timeline": {"name": "GAN14 review", "fps": 60.0, "start_frame": 216000, "start_tc": "01:00:00:00",
               "width": 1920, "height": 1080, "drop_frame": false, "duration": 742.4},
  "style": {"pacing": "medium", "zooms": "mix", "transitions": "hard cuts + whoosh at chapters",
            "captions": "srt", "popups": "terms + numbers", "humor": "only real funny moments"},
  "summary": "Plain-English plan in 2-4 sentences, shown at the top of the sheet.",
  "items": []
}
```

- `plan.py init` fills `timeline` from the snapshot and probe. Don't hand-edit it.
- `channel` is `syrian-rubik` or `srb-gamer`.
- `style` records his checkpoint-A choices. The learning loop reads them.

## 2. Item fields (all types)

| Field | Required | Meaning |
|---|---|---|
| `id` | yes | Short and unique: Z01 zoom, B01 B-roll, S01 sfx, P01 popup, F01 freeze, X01 transition, C01 chapter, N01 note, R01 fix, K001 caption |
| `type` | yes | `zoom` `broll` `sfx` `popup` `freeze` `caption` `transition` `chapter` `note` `fix` |
| `at` | yes | Seconds from the start of **his timeline** (same clock as review.mp4, words.json, the sheets) |
| `dur` | zoom/broll/popup/freeze/caption | Seconds on screen. sfx: optional (default = the file length) |
| `why` | strongly | Short reason. Shown on the sheet and in the marker note; used by learning |
| `quote` | nice | The words he says at that moment (Arabic as said) |
| `label` | optional | Short ASCII for the marker name (default = the type). Example: "cube explode" |
| `marker` | optional | Override: `true`/`false`. Default: every type except sfx and caption gets a marker |
| `status` | optional | `"rejected"` = he said no (kept for learning, never applied). `"unsure"` = you are not sure: nothing is placed, only a red marker, so he decides |
| `confidence` | optional | 0–1, your own certainty; the sheet doesn't show it |
| `asset` | broll/sfx | `{"ref": "<library id or path or candidate:src:id>", "in": 1.0, "audio": false}` |
| `params` | per type | See below |

## 3. Type-by-type params

**zoom**: (`shake` = impact zoom for funny hits: hard punch-in that jitters and calms down over 0.3-1.5 s; scale 1.08+) `{"scale": 1.25, "center": [0.5, 0.6], "mode": "hard"|"smooth"|"shake", "ease": 0.3, "out": false}`
- `scale` is 1.01–4.0 (1.25 = 125%).
- `center` is the point to push toward, 0–1 from the top-left.
- `hard`: a zoomed copy of his clip sits on `ED ZOOM` for `dur`, so it starts and ends with a cut.
- `smooth`: the copy gets a Fusion Transform that eases from 100% to `scale` over `ease` seconds. With `out: true` it eases back at the end. If Fusion fails, it falls back to `hard`.

**broll**: `{"fit": "fill"|"fit", "scale": 1.0}` plus `asset.in` (seconds into the clip) and `asset.audio` (bool).
- `fill` scales the clip to cover the frame. `fit` keeps letterbox bars. `scale` multiplies on top.

**sfx**: `{"gain_db": -4, "align": "peak"|"start"}`
- `peak` puts the sound's loudest moment on `at`. `start` puts the first sample on `at`.
- `gain_db` is applied to a loudness-matched copy (0 ≈ −20 dBFS loud part, which sits under speech).
- Two lanes (`ED SFX 1`, `ED SFX 2`). A third sound overlapping both is skipped, with a note.

**popup**: `{"text": "PLL", "style": "pop"|"number"|"label"|"warning"|"caption", "position": "top"|"upper"|"center"|"lower"|"bottom"|[x,y], "scale": 1.0, "rotate": 0, "color": "#fff"}`

**freeze**: `{"scale": 1.0, "center": [0.5, 0.5]}`. A still of his clip's exact frame at `at`, held for `dur`. Add a separate `sfx` item for the sting.

**caption**: `{"text": "...", "style": "caption", "position": "bottom"}`. Normally generated by `plan.py captions` (ids K001...).

**transition**: `{"kind": "whip"|"zoom"|"dip"|"flash"|"cross", "dur_frames": 10}`. By hand (red marker). Put `at` on the cut.

**chapter**: `{"title": "..."}`. Marker plus a line in the upload notes.

**note** / **fix**: `{"text": "..."}`. Red/cream markers for things only he can do (cut a pause, fix audio, mute game music).

## 4. What the validator checks (`plan.py validate [--strict]`)

**Errors (nothing gets applied):**
- wrong schema; a bad or duplicate id; an unknown type; a negative `at`, or an item that starts or runs past the end
- a missing `dur`
- a zoom scale outside 1.01–4.0; a center outside 0–1; a bad zoom mode
- B-roll or SFX without `asset.ref`, or with an asset not found
- an NC/ND license; an outside asset without a license record
- a B-roll `in + dur` longer than the clip
- a popup or caption without text; a chapter without a title
- two items overlapping on the same track
- more than 999 markers
- with `--strict` (apply uses it): any `candidate:` asset that is still not downloaded

**Warnings (think, then decide):**
- B-roll held over 6 s
- a zoom over 150%; zooms less than 2 s apart
- three sounds within 0.3 s; the same sound used 5 or more times
- text on screen too short to read
- a caption line over 42 characters
- nothing visual in the first 10 s
- chapter problems (not starting at 0:00, fewer than 3, closer than 10 s)
- an unindexed file
- no `why`

## 5. Tracks, colors and markers the bridge creates

**Video tracks** (bottom to top, all above his tracks): `ED ZOOM` → `ED B-ROLL` → `ED TEXT` → `ED CAPTIONS`.
**Audio tracks:** `ED SFX 1`, `ED SFX 2`, `ED B-ROLL AUDIO`.
**Placed clips** are colored Orange so he can spot them.

**Marker colors** (default legend; preferences may change it):

| Type | Color |
|---|---|
| broll | Blue |
| zoom | Yellow |
| sfx | Green |
| transition | Purple |
| popup and caption | Cyan |
| freeze | Pink |
| fix | Red |
| note | Cream |
| chapter | Sand |
| anything he must do by hand | **Red**, with "DO BY HAND (reason)" in the note |

- **Marker name:** `ID label` in ASCII.
- **Note:** `Type: why | instruction | says: quote`.
- **Hidden id:** `editor:vN:ID`, which is how the skill removes only its own markers.
- **Only one marker per frame.** A clash moves the second marker forward one frame.
